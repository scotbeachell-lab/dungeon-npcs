# Dungeon NPCs

A small Godot 4 dungeon built with Kenney's **Mini Dungeon** kit. Human and orc NPCs wander, chat, gossip, trade, brawl, sit and loot chests.
Two messenger NPCs can also tell you about your day:

- **Postie Pip** announces new Gmail.
- **Herald Hruk** announces Google Calendar events.

The Godot project is in [`dungeon_npcs/`](dungeon_npcs/). Open `dungeon_npcs/project.godot` in Godot 4.3+ and press **F5**.
See [`dungeon_npcs/README.md`](dungeon_npcs/README.md) for the controls, Gmail and Calendar setup, and running at Windows startup.

Your Gmail and calendar settings are stored outside the project, in `%APPDATA%\Godot\app_userdata\Dungeon NPCs\`, so they are never part of this repository.

3D models: [Kenney Mini Dungeon](https://kenney.nl/assets/mini-dungeon) (CC0), see `dungeon_npcs/assets/License.txt`.
